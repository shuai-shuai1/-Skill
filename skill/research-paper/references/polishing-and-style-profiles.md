# 论文润色与风格配置

## 核心原则

润色服务于论证，不替代科学判断。按以下顺序处理：

`论文类型 -> 章节任务 -> 主张/证据/边界 -> 全文一致性 -> 段落逻辑 -> 句子与格式`

如果数据、比较口径或因果链存在问题，先标出问题，再润色能够安全修改的部分。不得用流畅表达掩盖证据缺口。

## 五轴路由

开始前确定五个轴；未指定目标期刊时使用 `generic`，不猜测期刊要求。

| 轴 | 可选值 | 作用 |
|---|---|---|
| 任务 | `proofread`、`clarify`、`restructure`、`translate` | 控制改写强度 |
| 论文类型 | `research`、`methods`、`algorithmic`、`hypothesis`、`review` | 控制论证预期 |
| 章节 | title、abstract、introduction、methods、results、discussion、conclusion | 控制章节任务 |
| 语言 | 中文、英文、中译英、英译中 | 控制句法与术语策略 |
| 风格配置 | `generic`、`chinese-core`、`nature-family`、用户指定期刊 | 控制体例和读者范围 |

`nature-family` 只在用户明确指定 Nature 体系期刊时启用。Nature、Nature Communications 和 Nature Machine Intelligence 的格式与受众要求不同；最终定稿前必须核对具体期刊的最新官方指南。

## 四级修改强度

- `L0 Proofread`：错别字、语法、标点、编号与格式。不得改变句义。
- `L1 Clarity`：删冗余、解长句、明确指代和逻辑连接。不得改变主张强度。
- `L2 Structure`：重排句段、恢复章节任务、合并重复信息。需提供结构变更说明。
- `L3 Argument repair`：重建主张—证据—边界关系。只有证据充分且用户授权时执行；缺失内容用 `AUTHOR_INPUT_NEEDED` 标记，不得补写事实。

默认采用满足目标的最低强度。局部润色不自动扩大为全文重写。

## 润色前冻结项

记录并保持不变：

- 数据、指标定义、样本量、随机种子、比较对象和有效位数；
- 图表编号、公式含义、引用指向和已确认术语；
- 论文中心主张及其允许的结论范围；
- 用户明确要求保留的段落、模板和人工修改。

先建立术语表，至少包含规范术语、首次定义、缩写、来源中的变体和采用决定。一物一名，不为避免重复而轮换技术同义词。

## 全文一致性扫描

全文或多轮退修稿必须先扫描，再逐句润色：

1. 核对摘要、正文、表格、图和结论中的重复数字。
2. 检查百分比与百分点、平均值与单次结果、置信区间与标准差是否混用。
3. 检查方法名、数据集、指标、单位、缩写和符号是否漂移。
4. 检查结果是否被讨论段过度解释，结论是否超出实验边界。
5. 删除复述表格全部数值、重复上一句或只起衔接作用的空句。
6. 修改完成后重新扫描交叉引用、术语和关键数字。

## 算法与工程论文

读者主要判断：问题是否定义清楚、方法能否复现、比较是否公平、结果是否稳定、适用边界在哪里。

- 方法段区分“方法是什么”“为什么这样设计”“如何实现”。
- 结果主张同时给出数据集或场景、指标、baseline、差值和实验条件。
- 随机算法应报告种子或重复次数、不确定性和模型选择协议。
- 运行时间、实时性、部署或工程可用性必须绑定硬件、软件、输入规模、计时方法和目标阈值。
- 讨论需要呈现失败模式、资源代价、外部有效性和先验依赖，而非只解释优势。

## 章节任务

- `Abstract`：问题/缺口 -> 方法 -> 核心量化结果 -> 有边界的意义。摘要数字必须在正文中出现。
- `Introduction`：重要问题 -> 现有缺口 -> 本文如何填补 -> 可验证贡献。不要提前堆实现细节。
- `Methods`：输入、处理、参数、随机性、软件、选择标准和复现步骤完整。
- `Results`：报告发生了什么及其量化支持，避免把推测写成观察事实。
- `Discussion`：解释意义、替代解释、失败模式、限制和适用条件。
- `Conclusion`：中心贡献 -> 关键证据 -> 带边界的意义，不引入新结果。

## 风格配置

### `generic`

默认使用准确、克制、直接的学术表达。优先短主句和明确逻辑，不强制任何特定期刊的篇幅、标题或显著性叙事。

### `chinese-core`

优先符合中文工科期刊的术语、编号和层级习惯。减少口号式贡献、英语句法直译和连续长定语；结果使用“在给定条件下”“相比……提高 X 个百分点”等可核查表达。期刊模板和参考文献格式以目标刊最新要求为准。

### `nature-family`

面向更广读者，前置问题重要性和可理解的新意，但不得扩大证据范围。区分具体子刊配置；若只知道“Nature 系”，保持通用风格并列出需要核验的期刊要求。避免用高影响力措辞替代跨场景验证、独立证据和机制边界。

## 交付格式

默认交付：

1. 润色后文本；
2. 修改级别与风格配置；
3. 关键修改说明；
4. 冻结并保持不变的事实；
5. `AUTHOR_INPUT_NEEDED` 与未解决证据问题；
6. 全文任务附数字、术语和交叉引用复核结果。

用户要求对照时，使用“原文 / 修改稿 / 修改原因”。不要把纯语言修改描述成科学质量已经提高。
