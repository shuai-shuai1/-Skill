# 可复现数据图

## 图件任务

一张数据图必须服务一个明确主张。先填写 Figure Specification，再决定是否需要绘图；少于三个数据点、单一数值或需要大量精确查表的数据，优先使用正文或表格。

## 工具选择

- Python/Matplotlib：默认，适合训练曲线、混淆矩阵、消融、性能和误差图。
- R/ggplot2：适合统计建模、分布和社会科学图。
- MATLAB：适合信号、控制、频谱和仿真图。
- Origin：用户已有工程和期刊模板时可使用，但仍需保留源数据和导出记录。

## 图型决策

| 问题 | 推荐图型 | 避免 |
|---|---|---|
| 类别间数值比较 | 点图、柱状图、带区间点图 | 3D 柱图、饼图 |
| 分布比较 | 箱线、小提琴、ECDF | 只画均值柱图 |
| 随时间或 epoch 变化 | 折线与不确定性带 | 无平滑说明的过度平滑 |
| 两个连续变量关系 | 散点、回归和置信区间 | 只报告相关系数 |
| 多指标相关 | 热图或小倍图 | 信息过密散点矩阵 |
| 分类误差结构 | 归一化混淆矩阵 | 只报告 accuracy |
| 模型比较 | 点图、分组柱图、临界差异图 | 隐藏方差的单值排名 |
| 消融 | 表格配合点图或小倍图 | 同时改变多个因素 |
| 计算代价与性能 | Pareto 散点或双面板 | 无说明的双 y 轴 |

## 数据来源

每张图记录：

- 输入数据文件和内容哈希；
- 生成脚本和参数；
- 对应运行 ID、checkpoint 或表格；
- 数据类型：真实、推导、理论或 synthetic；
- 数据清洗、聚合、归一化和平滑方法；
- 生成时间与软件版本。

不要把从 PDF 或截图人工读取的近似值当成原始实验数据。必须使用时，标为 digitized/approximate 并保留来源页码。

## 通用视觉规范

- 白底、低饱和、少装饰；
- 颜色与 marker/线型共同编码，不能只靠红绿；
- 轴标签包含物理量、指标全称和单位；
- 网格线弱于数据；
- 图例靠近数据且术语与正文一致；
- 子图编号、字体、线宽、留白统一；
- 单栏和双栏尺寸分别测试；
- 输出 SVG/PDF 与至少 300 DPI PNG；
- 黑白和色觉缺陷条件下仍可区分。

## 不确定性

- 均值比较报告 SD、SE、CI 或重复实验分布，并说明类型；
- 只有一次运行时不要画虚假的误差棒；
- 平滑曲线同时保留原始趋势或说明窗口；
- 不截断 y 轴夸大差异，必须截断时明确标记；
- 对多个随机种子使用同一聚合规则。

## 深度学习图件

### 训练曲线

区分训练、验证和测试。测试曲线通常不应逐 epoch 用于模型选择。标明 epoch、指标、平滑和最佳 checkpoint 规则。

### 混淆矩阵

明确原始计数或按真实类别归一化。类别很多时，论文版可保留数值，投影版可去除密集数字，但必须保留轴和色条。不得交换行列而不更新说明。

### 消融图

一次只改变声明的因素。图注说明共享的数据、预算和种子。模块组合较多时优先用表格，图只呈现关键趋势。

### UMAP、t-SNE 等嵌入

说明随机种子、距离度量、邻居数和输入层。嵌入只用于可视化，不把簇间距离直接解释为原空间统计结论。

## 图文闭环

1. 公式定义指标；
2. 表格给精确数值；
3. 图展示趋势、分布或误差结构；
4. 正文解释决策相关信息；
5. 讨论说明边界。

图中数值必须回读并与源数据、表格和正文比较。运行 `figure_qa.py` 只能验证基础图像属性，不能替代科学和视觉检查。
